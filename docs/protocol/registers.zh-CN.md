# 寄存器参考

## 寄存器用法

每个寄存器都可以按多种数据类型访问。本节描述常见映射，以及每个寄存器的语义。

### 映射

当寄存器以整数类型访问时，使用以下映射将底层浮点值编码为整数值。

#### 电流（单位：安培）

- int8 => 1 LSB => 1A
- int16 => 1 LSB => 0.1A
- int32 => 1 LSB => 0.001A

#### 转矩（单位：N*m）

- int8 => 1 LSB => 0.5 N*m
- int16 => 1 LSB => 0.01 N*m
- int32 => 1 LSB => 0.001 N*m

#### 电压（单位：伏特）

- int8 => 1 LSB => 0.5V
- int16 => 1 LSB => 0.1V
- int32 => 1 LSB => 0.001 V

#### 温度（单位：摄氏度）

- int8 => 1 LSB => 1 C
- int16 => 1 LSB => 0.1C
- int32 => 1 LSB => 0.001 C

#### 时间（单位：秒）

- int8 => 1 LSB => 0.01s
- int16 => 1 LSB => 0.001s
- int32 => 1 LSB => 0.000001s

#### 位置（单位：转）

- int8 => 1 LSB => 0.01 转 => 3.6 度（范围为 -1.27 到 1.27）
- int16 => 1 LSB => 0.0001 转 => 0.036 度（范围为 -3.2767 到 3.2767）
- int32 => 1 LSB => 0.00001 转 => 0.0036 度

#### 速度（单位：转 / 秒）

- int8 => 1 LSB => 0.1Hz / 36 dps
- int16 => 1 LSB => 0.00025 Hz > 0.09 dps
- int32 => 1 LSB => 0.00001 Hz => 0.0036 dps

#### 加速度（单位：转 / 秒^2）

- int8 => 1 LSB => 0.05 l/s^2
- int16 => 1 LSB => 0.001 l/s^2
- int32 => 1 LSB => 0.00001 l/s^2

#### PWM 与 kp/kd 比例（无量纲）

- int8 => 1 LSB => (1/127) - 0.007874
- int16 => 1 LSB => (1/32767) - 0.000030519
- int32 => 1 LSB => (1/2147483647) - 4.657e-10

#### 功率（单位：W）

- int8 => 1 LSB => 10.0 W
- int16 => 1 LSB => 0.05 W
- int32 => 1 LSB => 0.0001 W

## 寄存器

### 0x000 - 模式（Mode）

模式：读/写

伺服器当前的运行模式。并非所有值都可写入。

- 0 => 已停止（stopped）= 可写，清除故障
- 1 => 故障（fault）
- 2,3,4 => 准备运行
- 5 => PWM 模式
- 6 => 电压模式
- 7 => 电压 FOC
- 8 => 电压 DQ
- 9 => 电流
- 10 => 位置
- 11 => 超时
- 12 => 零速度
- 13 => 保持在范围内（stay within）
- 14 => 测量电感
- 15 => 制动（brake）

发送命令时，该寄存器必须在命令帧中的任何其他寄存器之前写入。

### 0x001 - 位置（Position）

模式：只读

伺服器的当前位置，以输出轴的转数计量。最大负整数被保留，不会被报告。

### 0x002 - 速度（Velocity）

模式：只读

伺服器的当前速度，以输出轴处的 Hz 计量。

### 0x003 - 转矩（Torque）

模式：只读

在输出轴处测得的当前施加转矩。

### 0x004 - 测得的 Q 相电流

模式：只读

Q 相中的电流，以安培计量。

### 0x005 - 测得的 D 相电流

模式：只读

D 相中的电流，以安培计量。

### 0x006 - 测得的绝对位置

模式：只读

如果在 ABS 端口上配置了绝对编码器，则其值将以转数为单位在此报告。

### 0x007 - 测得的电功率

模式：只读

若为正值，则为施加到电机的估算电功率。若为负值，则为施加到直流输入母线的功率。

### 0x00a - 电机温度

模式：只读

当前电机温度，以摄氏度计量。仅当 NTC 热敏电阻连接到 TEMP 焊盘、`servo.motor_thermistor_ohm` 设置为正确的电阻值且 `servo.enable_motor_temperature` 设置为 1 时，该值才有效。

### 0x00b - 轨迹完成

模式：只读

若当前受加速度或速度限制的轨迹已完成，并且控制器正在跟随最终速度，则为非零。

### 0x00c - 归位状态（Home state）

模式：只读

* 0 - *仅相对（relative only）* - 位置未参照任何基准
* 1 - *转子（rotor）* - 位置以转子为基准
* 2 - *输出（output）* - 位置已参照到输出，无论是通过输出参考编码器，还是通过“set output nearest”或“set output exact”命令


### 0x00d - 电压（Voltage）

模式：只读

当前输入电压。

### 0x00e - 温度（Temperature）

模式：只读

当前板级温度，以摄氏度计量。

### 0x00f - 故障代码（Fault code）

模式：只读

当主模式为 1（故障）时将被设置的故障代码。

* 32 - *校准故障（calibration fault）* - 编码器在校准期间无法感应到磁体
* 33 - *电机驱动故障（motor driver fault）* - 最常见的原因是欠压，moteus 尝试从电源汲取的电流超过电源所能提供的电流。其他电气故障也可能报告此错误，`drv8323` 诊断树中有更多信息。
* 34 - *过压（over voltage）* - 母线电压超过了 `servo.max_voltage`。这可能由配置错误引起，或者当控制器向无法吸收功率的电源回馈功率且未配置磁通制动时发生。
* 35 - *编码器故障（encoder fault）* - 编码器读数与存在磁体不一致。
* 36 - *电机未配置（motor not configured）* - 尚未在该电机上运行 `moteus_tool --calibrate` 过程。
* 37 - *PWM 周期溢出（pwm cycle overrun）* - 内部固件错误
* 38 - *过温（over temperature）* - 已超过配置的最高温度
* 39 - *超出界限（outside limit）* - 尝试在超出 `servopos.position_min` 和 `servopos.position_max` 配置的界限之外启动位置控制。
* 40 - *欠压（under voltage）* - 电压过低
* 41 - *配置已更改（config changed）* - 运行期间更改了需要停止的配置值
* 42 - *theta 无效（theta invalid）* - 没有可用的有效换向编码器
* 43 - *位置无效（position invalid）* - 没有可用的有效输出编码器
* 44 - *驱动使能故障（driver enable fault）* - MOSFET 栅极驱动器无法启用
* 45 - *停止位置已弃用（stop position deprecated）* - 尝试将已弃用的“停止位置”功能与速度或加速度限制一起使用。建议改为直接以目标速度 0.0 命令期望位置，或者退而求其次，禁用加速度和速度限制。
* 46 - *时序违规（timing violation）* - 启用了内部检查，且控制器违反了内部时序约束
* 47 - *反电动势前馈无加速度（bemf feedforward no accel）* - 配置了 `servo.bemf_feedforward`，但未指定加速度限制。如果你*确实*知道自己在做什么，可以用 `servo.bemf_feedforward_override` 禁用此检查。
* 48 - *无效界限（invalid limits）* - `servopos.position_min` 或 `servopos.position_max` 为有限值且超出可用位置范围
* 49 - *位置控制错误（position control error）* - 位置控制误差超过了 `servo.fault_position_error` 中配置的阈值
* 50 - *速度控制错误（velocity control error）* - 速度控制误差超过了 `servo.fault_velocity_error` 中配置的阈值

在有效的控制模式期间，也可能出现一些非零代码，但并不代表故障。这些代码表示（如果有的话）是哪个函数在限制控制器的输出功率。

* 96 - `servo.max_velocity`
* 97 - `servo.max_power_W`
* 98 - 最大系统电压
* 99 - `servo.max_current_A`
* 100 - `servo.fault_temperature`
* 101 - `servo.motor_fault_temperature`
* 102 - 命令的最大转矩
* 103 - `servopos.position_min` 或 `servopos.position_max`


### 0x010 / 0x011 / 0x012 - PWM 相 A / B / C

模式：读/写

当处于 Pwm 模式时，这控制相 A、B 和 C 的原始 PWM 值。若未指定，则使用 0.0。

### 0x014 / 0x15 / 0x16 - 电压相 A / B / C

模式：读/写

当处于 Voltage 模式时，这控制施加到相 A、B 和 C 的电压。若未指定，则使用 0.0。


### 0x018 - 电压 FOC Theta

模式：读/写

当处于 Voltage Foc 模式时，这控制期望的电相位。整数类型使用 PWM 映射。若未指定，则使用 0.0。

### 0x019 - 电压 FOC 电压

模式：读/写

当处于 Voltage Foc 模式时，这控制期望施加的相电压。若未指定，则使用 0.0。

### 0x01a - D 电压

模式：读/写

当处于 Voltage Dq 模式时，这控制期望施加的 D 电压。若未指定，则使用 0.0。

### 0x01b - Q 电压

模式：读/写

当处于 kVoltageDq 模式时，这控制期望施加的 Q 电压。若未指定，则使用 0.0。

### 0x01c - 命令的 Q 相电流

模式：读/写

当处于 Current 模式时，这控制期望的 Q 相电流。若未指定，则使用 0.0。

### 0x01d - 命令的 D 相电流

模式：读/写

当处于 Current 模式时，这控制期望的 D 相电流。除非你喜欢浪费功率，否则对于 BLDC 电机，通常希望将其设置为 0。若未指定，则使用 0.0。

### 0x1e - 电压 FOC Theta 速率

模式：读/写

当处于 Voltage Foc 模式时，这控制电相位的变化速率。整数类型使用速度映射。


### 0x020 - 位置命令

模式：读/写

当处于 Position 模式时，这控制期望的位置。

最大负整数，或浮点的 NaN，表示“使用当前位置值”。

若未指定，则使用 0.0。

注意，在没有任何已配置或已命令的速度或加速度限制的情况下，控制器将依据 kp 和 kd 常量尝试*立即*达到该位置。

### 0x021 - 速度命令

模式：读/写

当处于 Position 模式时，以给定的速度（单位 Hz）推进期望位置。

作为一种特殊情况，如果 0x020 位置未设置，而 0x026 停止位置已设置，则该值的符号会被忽略，改为选择使电机朝停止位置移动的方向。

最大负整数，或浮点的 NaN，与 0.0 处理方式相同。

若未指定，则使用 0.0。

### 0x022 - 前馈转矩

模式：读/写

当处于 Position 模式时，在应用所有常规控制环之后，再加上给定的前馈转矩。注意，这是输出轴处的转矩。若未指定，则使用 0.0。

### 0x023 - Kp 比例

模式：读/写

当处于 Position 模式时，将比例控制项按给定因子缩小。整数类型按 PWM 方式应用。若未指定，则使用 1.0。

### 0x024 - Kd 比例

模式：读/写

当处于 Position 模式时，将微分控制项按给定因子缩小。整数类型按 PWM 方式应用。内部会将其限制为不超过 kp 比例。若未指定，则使用 1.0。

### 0x025 - 最大转矩

模式：读/写

当处于 Position 模式时，要施加的最大转矩。

最大负整数，或浮点的 NaN，使用由 `servo.max_current_A` 推导出的系统范围配置的最大转矩。

若未指定，则使用 NaN。

### 0x026 - 命令的停止位置

模式：读/写

当处于 Position 模式且命令了非零速度时，在到达给定位置时停止运动。NaN / 最大负值表示不施加限制。若未指定，则使用 NaN。

注意，如果控制器被命令朝*远离*停止位置的方向移动，比如速度命令与起始和停止位置不一致，那么它将表现得如同已命令 0 速度且当前命令位置等于停止位置一样。

注意：此寄存器已弃用。该选项的大多数用户应改为使用加速度或速度限制。

### 0x027 - 看门狗超时（Watchdog timeout）

模式：读/写

这决定此命令的有效时长。如果此超时在收到另一个命令之前到期，控制器将进入超时状态。默认值为 0.0，表示使用系统范围配置的默认值。NaN / 最大负值表示不施加强制超时。

### 0x028 - 速度限制

模式：读/写

这可用于覆盖内部生成轨迹的全局速度限制。

若为负值，则不施加限制。

若未指定，则为 NaN / 最大负值，表示使用全局可配置默认值。

### 0x029 - 加速度限制

模式：读/写

这可用于覆盖内部生成轨迹的全局加速度限制。

若为负值，则不施加限制。

若未指定，则为 NaN / 最大负值，表示使用全局可配置默认值。

### 0x02a - 固定电压覆盖

模式：读/写

若已指定且非 NaN，则控制模式将暂时处于“固定电压”模式，无论 `servo.fixed_voltage_mode` 的当前设置如何。

### 0x02b - Ki 积分限幅比例

模式：读/写

当处于 Position 模式时，将积分项的积分限幅（windup limit）按给定因子缩小。整数类型按 PWM 方式应用。若未指定，则使用 1.0。

### 0x02c - 固定电流覆盖

模式：读/写

若已指定，则控制模式将暂时处于“固定电流”模式。这与“固定电压”模式类似，但控制的不是固定电压，而是固定的 D 轴电流。

### 0x02d - 忽略位置界限

模式：读/写

若已指定且非零，则 `servopos.position_min` 和 `servopos.position_max` 将被忽略。

### 0x030 - 比例转矩

模式：读

这报告 PID 控制器中比例项贡献的转矩。

### 0x031 - 积分转矩

模式：读

这报告 PID 控制器中积分项贡献的转矩。

### 0x032 - 微分转矩

模式：读

这报告 PID 控制器中微分项贡献的转矩。

### 0x033 - 前馈转矩

模式：读

这报告 PID 控制器中的前馈贡献。

### 0x034 - 总控制转矩

模式：读

这报告位置模式控制器命令的总转矩。该值也报告在 0x03a 中。

### 0x038 - 控制位置

模式：读

这报告当前轨迹控制位置，在有效的模式下。当启用速度或加速度限制时，控制位置将遵循期望的限制以达到命令位置。

### 0x039 - 控制速度

模式：读

这报告当前速度控制值，在有效的模式下。当启用速度或加速度限制时，控制速度将遵循期望的限制以达到控制位置和速度。

### 0x03a - 控制转矩

模式：读

控制环命令的转矩。这与 0x034 相同。

### 0x03b - 位置误差

模式：读

当前感测位置减去控制位置。

### 0x03c - 速度误差

模式：读

当前感测速度减去控制速度。

### 0x03d - 转矩误差

模式：读

当前感测转矩减去控制转矩。


### 0x040 - 保持在范围内下界

模式：读/写

当处于 Stay Within 模式时，这控制允许的最小位置。最大负整数或浮点的 NaN 表示“没有下界”。当处于特殊值或位置高于此界限时（同时还要遵守可选的上界），仅施加前馈转矩。当超出此界限时，使用 PID 控制器将位置强制拉回该界限。若未指定，则使用 0.0。

### 0x041 - 保持在范围内上界

模式：读/写

当处于 Stay Within 模式时，这控制允许的最大位置。最大负整数或浮点的 NaN 表示“没有上界”。当处于特殊值或位置低于此界限时（同时还要遵守可选的下界），仅施加前馈转矩。当超出此界限时，使用 PID 控制器将位置强制拉回该界限。若未指定，则使用 0.0。

### 0x042 - 前馈转矩

0x022 寄存器的影子。

### 0x043 - Kp 比例

0x023 寄存器的影子。

### 0x044 - Kd 比例

0x024 寄存器的影子。

### 0x045 - 最大转矩

0x025 寄存器的影子。

### 0x046 - 看门狗超时

0x027 寄存器的影子。

### 0x047 - Ki 积分限幅比例

0x02b 寄存器的影子。

### 0x048 - 忽略位置界限

0x02d 寄存器的影子。

### 0x050 - 编码器 0 位置

模式：只读

报告在插槽 0 中配置的编码器的当前滤波位置。

### 0x051 - 编码器 0 速度

模式：只读

报告在插槽 0 中配置的编码器的当前滤波速度。

### 0x052 - 编码器 1 位置

模式：只读

报告在插槽 1 中配置的编码器的当前滤波位置。

### 0x053 - 编码器 1 速度

模式：只读

报告在插槽 1 中配置的编码器的当前滤波速度。

### 0x054 - 编码器 2 位置

模式：只读

报告在插槽 2 中配置的编码器的当前滤波位置。

### 0x055 - 编码器 2 速度

模式：只读

报告在插槽 2 中配置的编码器的当前滤波速度。

### 0x058 - 编码器有效性

模式：只读

返回一个位域（bitfield），其中 bit 0 表示编码器 0 是否活动，bit 1 表示编码器 1 是否活动，以此类推。

| Bit | Value             |
|-----|-------------------|
| 0   | Source 0 Theta    |
| 1   | Source 0 Velocity |
| 2   | Source 1 Theta    |
| 3   | Source 1 Velocity |
| 4   | Source 2 Theta    |
| 5   | Source 2 Velocity |

### 0x05c - Aux1 GPIO 命令

模式：读/写

aux1 上配置为输出的任何 GPIO 的当前输出命令，以位域表示。并非所有位都会被使用，因为 bit 0 始终对应引脚 1，无论其是否配置为 GPIO 输出。

### 0x05d - Aux2 GPIO 命令

模式：读/写

aux2 上配置为输出的任何 GPIO 的当前输出命令，以位域表示。并非所有位都会被使用，因为 bit 0 始终对应引脚 1，无论其是否配置为 GPIO 输出。

### 0x05e - Aux1 GPIO 状态

模式：只读

aux1 上配置为输入的任何 GPIO 的当前输入值，以位域表示。并非所有位都会被使用，因为 bit 0 始终对应引脚 1，无论其是否配置为 GPIO 输入。

### 0x05f - Aux2 GPIO 状态

模式：只读

aux2 上配置为输入的任何 GPIO 的当前输入值，以位域表示。并非所有位都会被使用，因为 bit 0 始终对应引脚 1，无论其是否配置为 GPIO 输入。

### 0x060/0x064 - Aux1 模拟输入

模式：只读

aux1 上配置的任何模拟输入的当前输入值。这些寄存器与引脚 1-5 相关联，无论它们是否配置为模拟输入。每个值按 PWM 方式从 0 缩放到 1。

### 0x068/0x06c - Aux2 模拟输入

模式：只读

aux2 上配置的任何模拟输入的当前输入值。这些寄存器与引脚 1-5 相关联，无论它们是否配置为模拟输入。每个值按 PWM 方式从 0 缩放到 1。

### 0x070 - 毫秒计数器

模式：只读

每毫秒递增一次。当达到所查询类型的最大值时会回绕到该类型的最小值。对于浮点类型，它从 0 计数到 8388608 的整数。

### 0x071 - 时钟微调（Clock Trim）

模式：读/写

一个整数，可以微调 moteus 控制器上微处理器的时钟速率。正值使其加速，负值使其减速。每个整数步长大约对应 0.25% 的速度变化。

警告：更改速度会影响微控制器驱动的所有过程，包括 CAN 通信。因此，将其设置为非零值可能会妨碍后续的 CAN 通信。

### 0x072 - Aux1 PWM 输入周期

模式：只读，支持 int16/int32/float

当某个引脚配置为 `pwm_in` 模式时，报告 Aux1 PWM 输入引脚上上升沿之间的周期（单位微秒）。如果约 100ms 内未检测到信号，则返回 0。可用于计算风扇 RPM：`RPM = 60000000 / (period_us * pulses_per_rev)`。典型的 PC 风扇每转输出 2 个脉冲。

可测量的周期范围约为 10us 到 65535us。对于 2 脉冲/转的风扇，这大约对应 460 到 3,000,000 RPM。

### 0x073 - Aux1 PWM 输入占空比

模式：只读

将 Aux1 PWM 输入引脚上的信号占空比报告为 0.0 到 1.0 的浮点小数。整数类型使用 PWM 映射。若未检测到信号，则返回 NaN（或整数类型的最大负值）。

### 0x074 - Aux2 PWM 输入周期

模式：只读，支持 int16/int32/float

当某个引脚配置为 `pwm_in` 模式时，报告 Aux2 PWM 输入引脚上上升沿之间的周期（单位微秒）。如果约 100ms 内未检测到信号，则返回 0。可用于计算风扇 RPM：`RPM = 60000000 / (period_us * pulses_per_rev)`。典型的 PC 风扇每转输出 2 个脉冲。

可测量的周期范围约为 10us 到 65535us。对于 2 脉冲/转的风扇，这大约对应 460 到 3,000,000 RPM。

### 0x075 - Aux2 PWM 输入占空比

模式：只读

将 Aux2 PWM 输入引脚上的信号占空比报告为 0.0 到 1.0 的浮点小数。整数类型使用 PWM 映射。若未检测到信号，则返回 NaN（或整数类型的最大负值）。

### 0x076/0x07a - Aux1 PWM 输出

模式：读/写

Aux1 上给定引脚的当前输出 PWM 值。整数类型使用 PWM 映射。

### 0x07b/0x07f - Aux2 PWM 输出

模式：读/写

Aux1 上给定引脚的当前输出 PWM 值。整数类型使用 PWM 映射。

### 0x100 - 型号编号（Model Number）

名称：型号编号
模式：只读

这返回一个 32 位型号编号。

### 0x101 - 固件版本

模式：只读

这返回一个 32 位固件版本，按字节编码为 major.minor.micro。例如，0x010304 表示版本 1.3.4。


### 0x102 - 寄存器映射版本

模式：只读

这返回一个表示如何解释所有寄存器的数字。


### 0x110 - 复用 ID（Multiplex ID）

名称：复用 ID
模式：可配置

这控制通过复用 RS485 总线访问设备时使用的主 ID。它只能介于 1 到 127 之间。（0 保留为广播地址）。

### 0x120 - 0x122 - 序列号

名称：序列号
模式：只读

这返回一个 96 位序列号，最低有效字在前。


### 0x130 - 设置输出最近（Set Output Nearest）

模式：只写

发送后，这会使伺服器选择一个整数个内部电机转数，使最终位置尽可能接近给定位置。

### 0x131 - 设置输出精确（Set Output Exact）

模式：只写

发送后，伺服器会将输出位置强制设为完全指定的值。

### 0x132 - 要求重新索引（Require Reindex）

模式：只写

以任何值发送后，伺服器将要求在任何控制开始之前重新定位任何索引位置。无论如何，位置都将重置为与当前编码器设置一致的任意值。

### 0x133 - 重新捕获位置和速度

模式：只写

以任何值发送后，且若处于“位置”模式，伺服器会将当前控制位置和速度重新初始化为感测到的值。这也会将任何预先存在的位置积分项强制置零。预计这主要会在当前施加转矩为 0 时使用，无论是由于就地的最大转矩限制为零，还是由于就地的 kp 和 kd 比例为零。

### 0x140 - 驱动故障 1

模式：只读

在故障条件下，电机驱动器为故障寄存器 1 报告的确切位域。最多可设置 16 位。仅当当前模式为故障（1）且故障代码为 33（电机驱动故障）时，该值才为非零。

### 0x141 - 驱动故障 2

模式：只读。

在故障条件下，电机驱动器为故障寄存器 2 报告的确切位域。最多可设置 16 位。仅当当前模式为故障（1）且故障代码为 33（电机驱动故障）时，该值才为非零。

### 0x150 - 0x153 - UUID

名称：UUID
模式：只读，仅 int32

这返回一个 128 位 UUID，这是打印在 mjbots 包装上并由 `moteus_tool --info` 返回的值。

### 0x154 - 0x157 - UUID 掩码

名称：UUID
模式：只写，仅 int32

若写入其中一个或多个字段，则此帧从这一点往后的内容将被丢弃，除非设备的对应 UUID 与所写入的内容匹配。

### 0x158 UUID 掩码功能

名称：支持 UUID 过滤
模式：只读

若 UUID 掩码可用，则返回非零。
