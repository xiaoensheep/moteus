# 转矩受限故障排查

如果 moteus 能够控制电机，但无法为你的应用需求产生足够的转矩（torque），本文描述了诊断步骤。

## 概述

有几种主要因素会限制转矩。

1. **配置错误**：属于这一类的情况包括未经整定的 PID 常数，或过于激进的电流限制或热限制。
2. **控制器或电机散热不足**：即使控制器和电机的规格适合应用，仍可能需要热管理来实现这些目标。
3. **控制器或电机规格过小**：如果仅靠热管理不够，或不切实际，那么可能需要更大的控制器或更大的电机。
4. **电源电压不足**：对于低 Kv 电机，电源电压可能成为限制因素。

## 诊断

首先，你需要弄清楚自己处于上述哪一类情况。为此，可以进行一些诊断并检查其他事项。

### 输出限制原因

从固件版本 2025-07-21 起，固件会在位置（position）模式下通过「fault」寄存器（register）报告是否存在限制输出电流的因素。可能的值如下：

- **96 max_velocity**：最大速度：如果观测到的速度（velocity）超过配置的最大速度，则会在会导致速度增加的方向上限制转矩。这通过 `servo.max_velocity` 配置。
- **97 max_power**：最大功率：输出总功率通过电路板功率配置和 `servo.max_power_W` 的组合进行限制。[更多信息请参见此文章](https://blog.mjbots.com/2025/03/29/moaar-power/)。
- **98 BEMF**：最大系统电压：电源电压与电机的反电动势（BEMF）以及相电阻共同作用，不允许施加更大的电流。
- **99 max_current**：最大电流：存在一个系统范围内的最大输出相电流，通过 `servo.max_current_A` 配置。
- **100 fault_temperature**：温度：板载 FET 温度传感器可以限制输出电流。在当前固件中，该阈值通过 `servo.fault_temperature`/`servo.temperature_margin` 设置。
- **101 motor_temperature**：温度：电机温度传感器也可以限制输出电流。这通过 `servo.motor_fault_temperature`/`servo.motor_temperature_margin` 配置。
- **102 max_torque**：最大转矩：在每次位置模式命令中，客户端都可以指定要使用的最大转矩。如果板载 PID 与命令的前馈转矩之和超过该值，就会发生限制。
- **103 position_bounds**：位置边界：如果当前位置超出 `servopos.position_min` 和 `servopos.position_max` 的范围，则会在将电机进一步推向边界外的方向上限制转矩。
- **104 flux_braking**：磁通制动（flux braking）：输入电压过高，控制器正在电机绕组中耗散能量。

### 其他可能性

如果上述限制标志都不存在，那么剩余的可能性包括：

#### PID 整定刚度不足

moteus 施加的转矩（除任何前馈转矩外）由期望位置与实测位置之间的误差，以及期望速度与实测速度之间的误差决定。如果控制该过程的常数过低，那么即使在误差很大时，moteus 也只会施加很小的转矩。

moteus 中一种常见的这种情况如下：

1. 创建了一个 PID 整定
2. 之后，使用 `motor_position.rotor_to_output_ratio` 配置了一个减速器
3. 哎呀，现在 moteus 几乎不输出转矩了

这里需要注意的重点是，moteus 控制环路的 PID 项是在任何减速器的\*输出端\*测量的。因此，如果 kp=1，就意味着对于\*输出端\* 1 转的误差，在\*输出端\*施加 1Nm 的转矩。使用减速器后，这意味着转子处的有效增益会按减速比的平方减小。

因此，在配置减速器之后，你可以重新整定 PID 增益，或将增益增加减速比的平方倍。

示例：

```
servo.pid_position.kp = 4
servo.pid_position.kd = 0.05
motor_position.rotor_to_output_ratio = 1
```

你测试后发现效果很好。然后你配置了那个一直存在的 8 倍减速器。

```
motor_position.rotor_to_output_ratio = 0.125
```

现在控制器突然几乎什么都不做了。为了获得等效的刚度，你现在需要将 kp 和 kd 增益提高 `8 ** 2 = 64` 倍。

```
servo.pid_position.kp = 256
servo.pid_position.kd = 3.2
```

#### 校准失效

如果你的校准（calibration）失效了，就会导致转矩不足。失效可能出于 [校准故障排查指南](calibration.zh-CN.md) 中的任何原因，包括：

- 感应磁铁未牢固地固定在转子上，例如某个连接处未使用粘合剂
- 感应磁铁超过了其额定温度
- 控制器安装发生偏移

要验证这些假设，请重新校准电机并再次检查。如果问题得到解决，那么你需要确定上述哪个问题最可能是罪魁祸首并加以解决。

#### 其他「类似限制」的情况

有些「类似限制」的特性不会通过故障码机制上报。如果配置了位置边界，控制位置会被限制在这些边界之内。这并不直接限制转矩，因此不会通过该机制上报。

类似地，如果命令速度超过了速度限制 `velocity.max_velocity` 或 `servo_stats.motor_max_velocity`，它会被截断以保持在内。这些限制也不会通过故障码机制上报。

## 解决办法

如果错误是配置错误，修正它即可完成。

如果错误不是配置错误，那么解决办法取决于造成限制的原因。

### 热限制

如果限制是热方面的，那么你的选择包括：

1. 对发热的部件进行散热
2. 为发热的部件换用更大的控制器或电机
3. 使用减速器，如果已经在使用减速器，则换用更大的减速器

### 最大电流

如果你达到了控制器的最大电流限制，那么你的选择包括：

1. 使用不同的电机
2. 使用电流限制更高的控制器
3. 使用减速器，如果已经在使用减速器，则换用更大的减速器

### BEMF 或 `servo_stats.motor_max_velocity`

如果你受电机的反电动势限制，那么你的选择包括：

1. 使用更高的电源电压
2. 使用 Kv 额定值更高的不同电机

### 最大功率

此时，你的选择包括：

1. 配置更高的 PWM 频率
2. 使用更大的控制器
3. 使用不同的电机
4. 使用减速器，如果已经在使用减速器，则换用更大的减速器

## 解决办法的注意事项

### 减速器

如果考虑使用减速器或更大的减速器，最大的注意事项是最大速度会相应地降低。

其次，大多数减速器都有背隙，会给你的系统增加静摩擦和动摩擦，并且可能对最大转矩或速度有限制，从而成为新的限制因素。

### PWM 频率

如果提高 PWM 频率以改善峰值功率，这也会降低 moteus 的效率，从而导致更低的连续输出电流和功率额定值。

### 散热

散热的明显缺点是噪音、可靠性降低，以及即使空载时也会增加功耗。
