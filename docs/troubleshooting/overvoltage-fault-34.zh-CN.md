# 过压故障 34 排查

moteus 无刷电机控制器既向电机提供功率，也（取决于模式及外部系统状态）可以充当发电机，这通常称为再生制动（regenerative braking）。充当发电机时，能量被送入输入直流母线——这会导致电压上升，上升速率取决于电源的特性。如果电压上升得足够高、持续的时间足够长从而触发它，[磁通制动](../guides/electrical-setup.zh-CN.md#flux-braking) 可能会使部分能量在电机绕组中消耗。如果再生制动能量快速增加，或大于所配置的磁通制动能够耗散的能量，电压就可能超过 `servo.max_voltage` 中配置的故障电压，从而触发过压（overvoltage）故障。

如果你的应用中出现了故障 34，可以尝试几种基本相互独立的方法来解决该问题。

## 配置加速度限制

要使磁通制动正常工作，再生功率增加的速率必须受到限制。最简单的方法是使用你的应用所能容忍的最低加速度限制。默认加速度限制可以通过以下可配置参数设置：

```
servo.default_accel_limit
```

或者，可以在每个位置模式命令中发送该限制。

如果你不知道合适的加速度是多少，你可以：

- 使用粗略估算，形式如「我知道系统需要在 Z 秒内从速度 X Hz 变化到速度 Y Hz，因此加速度为 (Y - X) / Z」
- 选择一个不太可能导致问题的大加速度限制，比如 10000Hz/s。然后逐步降低，直到你的应用出现问题。在问题开始出现的值之上选择一个留有充足裕量的最终值。

## 使用 `servo.max_regen_power_W` 限制再生功率

发电时，默认情况下 moteus 会将所有这些能量送回直流母线。如果电源具有不可忽略的阻抗，这会导致电压上升。通过设置 `servo.max_regen_power_W`，你可以限制允许流回母线的再生功率。任何超出部分都会通过注入 d 轴电流在电机绕组中预先耗散。

例如，允许不超过 50 瓦特的再生功率：

```
conf set servo.max_regen_power_W 50
```

将其设置为 `0` 会使所有再生能量都在电机绕组中耗散，从而在最大配置电流和系统电压的限度内阻止任何再生电流到达母线。将其设置为 `nan`（默认值）则完全禁用该功能。

与加速度限制配合使用时效果最佳。加速度限制控制制动转矩施加的速率，而 `max_regen_power_W` 耗散越过加速度限制的多余能量。

### 选择数值

- 如果你的电源无法吸收任何再生能量（例如没有母线电容的市电供电电源），请将其设置为一个较小的数字，如 `10` 或 `0`。
- 如果你的电源可以吸收一些电流（例如电池），请将其设置为大约 `V_bus * I_charge_max`。例如，一个可以接受 2A 充电电流的 24V 电池：`servo.max_regen_power_W 48`。
- 如果你不确定，从 `0` 开始，逐步增加，直到再次出现故障 34，然后大约回退 50%。

### 热方面的考虑

该功能注入的 d 轴电流会以热量形式在电机绕组中耗散功率。在最大电流（由 `servo.max_current_A` 设置）和电阻 R 下，最大持续耗散为 `1.5 * I² * R`。对于 R=0.05Ω 且最大电流为 40A 的电机，这是 120W。请确保电机能够承受额外的发热，尤其是在持续或反复减速的情况下。

## 降低输入电源对再生功率的阻抗

通过降低输入电源的阻抗，你可以降低给定再生能量下电压上升的速率。有几种方法可以实现这一点。

### 提高电池电流额定值

如果你使用可充电电池作为电源，可以选择充电电流额定值更高的电池。

### 增加母线电容

如果你使用无法接受再生能量的市电供电电源，或者不希望更换电池，可以在直流输入母线上增加额外的电容。这样做时有几个需要考虑的事项：

- **浪涌电流管理**：根据 [电气设置指南](../guides/electrical-setup.zh-CN.md#inrush-current-management)，你所使用的任何浪涌电流管理方案都必须能够承受额外的电容。如果你使用 mjbots 的 power_dist 或 mjpower-ss，系统总电容不得超过 4000uF。市电供电电源可能能够承受更大的母线电容，但应查阅其参考文档以确认。一般来说，电容越大越有利于解决过压故障，前提是不超过浪涌电流方案的限制。

- **电容额定值**：所选电容的电压额定值应足以承受母线预期出现的最大电压，并留有适合你应用的设计裕量。此外，ESR（等效串联电阻）应足够低，以控制电压上升的幅度。

### 改用电池

如果你使用市电供电电源，或许可以改用可充电的电池方案。这样做时，重要的是确保浪涌电流得到适当管理。

## 配置更改

如果上述方案无法解决问题，或系统性能仍未达到期望水平，还有一些其他参数可以起到一定帮助，尽管程度不如上述方案。

### `servo.flux_brake_margin_voltage`

磁通制动的工作原理是监测系统电压的滤波版本，并随着其升高在绕组中耗散更多能量。通过扩大该过程发生的电压范围，系统在电压上升时将有更多时间作出响应。相关的阈值点包括：

- `servo.max_voltage - servo.flux_brake_margin_voltage`：该电压是磁通制动开始的位置。
- `servo.max_voltage`：当电压达到此点时，过压故障将触发。

你可以增大 `servo.flux_brake_margin_voltage`，直到触发点大约比你的标称系统电压（如果使用电池则是满充电压）高 1V。你也可以同时增大 `servo.max_voltage` 和 `servo.flux_brake_margin_voltage`，以留出更大的余地。

### `servo.flux_brake_resistance_ohm`

该常数决定了在给定电压上升量下绕组中耗散的能量多少。较低的值更为激进，会耗散更多能量，但稳定性可能较差。除非你有良好的机制来验证稳定性，否则不建议将其降低到默认值的一半以下。

### `servo.max_current_desired_rate`

该配置值决定了期望电流能够变化的最大速率。默认情况下它相对较慢，为 10000A/s。不过，如果你之前提高过它，将其调低有助于降低再生功率增加的速率。如果你的应用能够容忍，进一步降低会提高磁通制动的有效性。
