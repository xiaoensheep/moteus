# 校准故障排查

在为 [moteus 控制器](https://mjbots.com) 搭配新电机时，你通常会先按照 [参考手册中的说明](../guides/calibration.zh-CN.md) 运行自动校准（calibration）流程。当系统运行良好时，这些步骤就足以让 moteus 对该电机执行基于磁场定向控制（FOC）的精确转矩（torque）控制。之后你可以继续 [快速入门](../quick-start.zh-CN.md) 中的其余步骤。但如果自动校准不起作用会怎样？本文描述了校准过程中最常见的失败模式。

不幸的是，大多数校准失败最终都表现为相同的症状，例如以下错误：

```
CAL timeout
```

或

```
encoder not an integral multiple of phase
```

因此，要解决这些问题，通常需要从本文最前面的条目开始，然后逐步处理到较不常见的问题。

## 感应磁铁问题

要使用板载编码器（encoder）正常工作，moteus 要求将一个径向磁化（diametrically magnetized）的感应磁铁牢固地固定在转子上，使其在 moteus 的磁编码器下方横向居中，并具有合适的空气间隙。让我们逐一来看这些要求。

首先，你需要一个 [径向磁化的磁铁](https://www.kjmagnetics.com/magdir.asp)。这是一种磁化轴沿侧向的磁铁，其北极指向圆盘的弧形侧面。这与轴向磁化的磁铁相反，后者的磁化轴指向平坦侧面。这里有许多可选方案。[mjbots.com](https://mjbots.com) 出售的每块 moteus 控制器都附带一块合适的磁铁，并且 [mjbots.com 也销售备用磁铁](https://mjbots.com/products/d42dia)。还有一些供应商提供耐更高温度的磁铁，例如 [Digi-Key 上的 Radial Magnets, Inc. 9049](https://www.digikey.com/en/products/detail/radial-magnets-inc/9049/6030786)。然而有时你是在将现有执行器改装为使用 moteus，其中已经有一个感应磁铁。坏消息是它可能兼容也可能不兼容 moteus，而且除非你了解其规格，否则很难确定它所需的最佳空气间隙。在这些情况下，通常最简单的方法是移除现有磁铁并更换为规格已知的磁铁，尤其是在难以获得合适空气间隙时。

第二，磁铁必须牢固地固定在转子上，绝不允许任何滑动。实际上，这意味着磁铁与转子之间的每个连接处都需要使用粘合剂。常用的粘合剂有氰基丙烯酸酯凝胶（强力胶）和环氧树脂。例如，如果使用了 3D 打印的垫片，磁铁必须粘在垫片上，垫片必须粘在转子上。转子转动时，磁铁必须随之转动。压配合可能会有问题，除非配合设计具有明确的公差；而依赖磁铁与其吸引物之间的摩擦则肯定行不通。

第三，磁铁必须横向正确定位。这意味着它需要居中于磁编码器下方。对于除 moteus-r4 之外的所有 moteus 控制器，这是位于螺栓分布圆的中心。对于 [moteus-r4](https://mjbots.com/products/moteus-r4-11)，你应该 [查看 2D CAD 图纸](https://github.com/mjbots/moteus/blob/main/hw/controller/r4.5/20210124-moteus-controller-r45-mechanical.pdf) 以确定磁铁的放置位置。

磁铁表面与编码器芯片表面之间还需要合适的空气间隙。对于 mjbots 销售的磁铁，2mm 接近最佳空气间隙，1.5mm - 2.5mm 的范围也适用。0.5mm - 8mm 的间距虽然可能可行，但性能会有所下降。

最后，控制器本身需要相对于定子和转子牢固安装。如果允许它移动或转动，那么测得的转子角度将无法匹配换相所需的实际电角度，同时也会降低输出端位置（position）控制的质量。

## 电气问题

导致校准失败的最常见电气问题是相线焊接不良或根本没有焊接。电机的相线必须与 moteus 相端子形成良好的连接。这意味着焊接时，焊点必须达到足够的温度并具有足够的助焊剂，使焊锡既充分浸润整根导线，又能渗入相线端子。冷焊点可能表现为焊锡未能完全填满焊点、未在所接触的表面形成合适的焊角，或在线、焊盘与焊锡之间出现可见瑕疵。这可能导致无连接或间歇性连接。以下视频展示了理想的结果应该是怎样的：

第二常见的电气问题是电机本身存在根本性损坏。这可能是相间短路、绕组极性错误或磁铁极性错误。这些问题通常只出现在二手电机、低质量电机或手工制作的电机上。最简单的排查方法是用已知正常工作的电机进行测试。

## 较不常见的感应磁铁问题

我观察到一些与感应磁铁相关的较不常见的问题。

在一种情况下，磁铁实际上被同时粘在了转子和一个固定的安装支架上，导致转子完全无法转动。

在其他情况下，磁铁被允许超过其额定工作温度。[moteus-r4、moteus-n1 和 moteus-c1 随附的磁铁](https://mjbots.com/products/diametric-disc-magnet?variant=44912247013537) 额定温度为 70°C。如果这是个问题，可以采购额定温度更高的磁铁，例如 [moteus-x1 随附的 mjbots 140°C 磁铁](https://mjbots.com/products/diametric-disc-magnet?variant=44912246751393)。

用于换相的感应磁铁必须牢固地固定在转子上，而\*不是\*固定在减速器的输出端或任何可能具有背隙（backlash）的连杆上。如果磁铁安装在减速器上，那么所需的角度精度很容易超出板载编码器的测量能力。带有背隙的连杆也存在同样的问题。

## 机械问题

如果转子无法自由转动，或承受了显著的负载，校准就可能失败。校准在连接多种减速器时都能工作，但最终摩擦和静摩擦（stiction）会超出该流程所能应对的范围。在某些情况下，你可以通过向 `moteus_tool --calibrate` 传递额外选项来提高校准锁定阶段使用的功率：

```
--cal-motor-power 5
```

单位是瓦特，默认值为 5。你可以提高该值，但在较高值时，你可能会在编码器校准过程中使电机过热。

如果无法找到合适的功率，那么可能需要将电机和控制器设计为一个子组件，先对其进行校准，然后再连接到减速器上。

## 坏消息

坏消息是校准过程中的错误检查并非万无一失。也就是说，一个已经损坏的配置仍有可能报告校准成功完成。两个最大的迹象表明校准实际上并未成功：校准过程中报告的 Kv 值严重错误，或者位置或转矩控制无法可靠工作。如果出现其中任何一种情况，你需要逐一排查上述潜在原因并逐一排除。

## 好消息

好消息是，只要你有一个正常工作的电机、一块合适的磁铁，磁铁牢固地固定在转子上且位置正确，并且相线焊接遵循了正确的工艺，校准几乎可以 100% 成功。
