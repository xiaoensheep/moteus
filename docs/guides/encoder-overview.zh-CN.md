# 编码器概述（Encoder Overview）

本节介绍 moteus 可配置为使用编码器来传感转子、输出或辅助设备的多种方式。如果你只打算使用板载同轴磁编码器，可以跳过本节。

## 介绍

moteus 使用编码器来正确控制电机。编码器提供所需的反馈，以了解电机的位置以及其移动速度。了解使用哪个（哪些）编码器以及如何配置它们，是你在设计系统时需要做出的关键决策之一，因为对于许多应用而言，编码器的选择是最大刚度、控制稳定性以及是否需要回零等性能参数的主要决定因素。

moteus 使用编码器服务于两个不同的目的。首先，它需要**换相**反馈——即电机定子与转子之间的电气关系，以便正确施加转矩。其次，它需要**输出**反馈——即输出轴的位置和速度，以跟随指令轨迹。单个编码器可以同时服务于这两个目的，也可以为每个目的使用单独的编码器。

好消息是，moteus 带有板载的 AS5047P 或 MA600 磁编码器，在许多应用中可以开箱即用。该编码器与电机同轴安装。对于许多使用场景，尤其是没有齿轮减速的场景，这就足够了。然而，如果你使用霍尔传感器、需要更高的分辨率，或者有齿轮减速器并希望测量减速器或其他辅助设备的输出，则需要添加其他编码器。

在本指南中，我们将介绍几种常见变体，其余内容请参阅[详细的编码器参考](../reference/encoders.zh-CN.md)。

## 常见配置

以下是你将遇到的最常见的编码器配置：

**默认配置（仅板载编码器）**：AS5047P 或 MA600 板载编码器同时充当换相和输出传感器。这对许多应用都很适用，尤其是未安装减速器的情况，或者安装了减速器但不需要输出的绝对位置、或允许回零步骤的情况。

**添加霍尔传感器**：霍尔效应传感器提供稳健的换相反馈，在高振动环境中或以成本为主要考虑因素时很有用。当用作唯一编码器时，由此产生的系统在低速和位置跟踪方面的性能较差。

**双编码器设置**：使用一个编码器进行换相（通常是板载编码器或霍尔传感器），并使用一个单独的高分辨率编码器进行输出位置检测，可为精密应用提供最佳性能。

这两种方案在下面单独的指南中有说明：

- [带霍尔效应的电机](hall-effects.zh-CN.md) - 添加用于换相的霍尔传感器
- [双编码器](dual-encoders.zh-CN.md) - 使用单独的编码器分别进行换相和输出

再次说明，有关编码器配置参数的详细信息，请参阅[详细的编码器参考](../reference/encoders.zh-CN.md)。
