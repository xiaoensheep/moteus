# PID 整定（PID Tuning）

在位置或速度模式下运行时，moteus 使用 P(I)D 控制器来确定每个瞬间施加多少转矩。控制此运行的常数需要由用户选择。整定不一定有挑战性，但确实需要你理解自己试图实现的目标。

## 理论

三个增益的用途：

**比例项（Proportional）**：此项施加一个与当前期望位置和当前测量位置之间误差成正比的恢复转矩。它以减速器输出端测得的每转误差多少 Nm 来度量。它直接控制控制器的“刚度”。如果单独使用，电机将对任何给定误差施加固定转矩，也就是说，如果你手动将电机从设定点移开 0.1 转，它将无限期地施加 0.1 * 该转矩；然后如果你将其移到距离设定点 0.2 转，它将施加 0.2 * 该转矩。

**微分项（Derivative）**：此项充当“阻尼”项，即粘性阻力。打个比方，如果比例项是悬挂系统中的弹簧，那么微分项就是悬挂系统中油的稠度。此项施加的转矩与期望速度和测量速度之间误差的幅值成比例。如果所有其他增益都为零，并且用手扰动电机，较大的增益会让你感觉像是在对抗更稠的流体阻力。

**积分项（Integrative）**：积分项施加一个与位置误差对时间积分成比例的转矩。许多（甚至大多数）moteus 系统完全不用积分项。积分项难以整定，并且会导致较差的瞬态响应。然而，它们是实现负载系统零稳态误差的唯一方法。没有积分项时，稳态误差虽然可能非常小，但永远不会为零。对于积分项，有两个参数需要选择：增益本身，以及抗积分饱和增益项。

## 步骤

位置控制 P(I)D 回路的参数设置在 `servo.pid_position` 中，由用户选择以实现期望的控制响应。大多数用户希望 PID 控制器对其应用而言具有良好的阻尼和足够的刚度。

以下是一个可能的整定步骤。最好在能够用手移动电机的配置下使用 tview 执行。在惯量、阻尼和摩擦方面接近代表性的负载最为理想，但有总比没有好。

1. 将 kp 设得较小，并将 kd、ki 和 ilimit 设为 0。
```
servo.pid_position.kp = 0.001
servo.pid_position.kd = 0
servo.pid_position.ki = 0
servo.pid_position.ilimit = 0
```
如果你对系统有所了解，可以选择更大的初始 kp，但你希望它是一个使恢复转矩非常平缓、并且你能轻松用手扰动系统的值。
2. 每次将 kp 增加 50%，直到达到期望的刚度。
    1. 测试当前值。可以使用 `d pos nan 0 nan` 之类的命令来“保持位置”。然后用手移动转子来判断刚度。
    2. 如果刚度不足，将 `servo.pid_position.kp` 增加 50%，然后回到 (a)。
    3. 如果出现振动或不稳定，将 `servo.pid_position.kp` 减小 2 倍，那大致就是一个良好的稳定最大值。
3. 整定微分项
    1. 初始将 kd 设为 kp 值的 1/100。例如，下面式子中的 FOO 为所选 `servo.pid_position.kp` 值的 0.01 倍。
`servo.pid_position.kd = FOO`
    2. 测试当前值。使用 `d pos nan 0 nan` 来保持位置。手动将电机移离设定点，然后迅速释放。如果“阻尼良好”，电机会在原位置平滑地停下。如果欠阻尼，电机可能会振荡。
    3. 如果阻尼不足，将 `servo.pid_position.kd` 增加 50%，然后回到 (a)。
    4. 如果出现高频振动或振荡，将 `servo.pid_position.kd` 减小 2 倍，那大致就是一个良好的稳定最大值。
4. 如果需要零稳态误差，则需要积分项。否则，将 `ilimit` 保持为 0 即可完成。
5. 配置积分项。
    1. 将 `servo.pid_position.ilimit` 设为比最大预期稳态转矩高 20%。
    2. 将 `servo.pid_position.ki` 的初始值设为等于 `servo.pid_position.kp` 项。
    3. 增加 `servo.pid_position.ki`，直到达到期望的响应。`ki` 很可能在数值上需要远大于 kp，大约大 10-1000 倍。可能需要比“保持位置”更具代表性的控制曲线来判断所选积分常数是否足够。

## 加速度受限轨迹

此外，*强烈*建议为 moteus 配置并使用一个你的系统在物理上可实现的加速度限制。这样做意味着“期望”位置和“期望”速度将遵循连续、物理上可实现的轨迹。

- `servo.default_accel_limit` 可以以 Hz/s 为单位设置。

如果你不设置加速度限制，或者选择的限制过高以致物理上无法实现，你的系统在运动过程中会出现超调，并且你会发现难以整定 P(I)D 参数来实现期望的响应。

## 不应整定的内容

“电流回路”的带宽设置在 `servo.pid_dq_hz` 中，其增益根据它以及校准得到的电机参数自动计算。用户通常不直接更改它。取而代之的是，在校准期间通过指定适当的 `--cal-bw-hz` 来选择它。
