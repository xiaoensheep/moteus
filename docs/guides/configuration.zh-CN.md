# 配置（Configuration）

在首次使用 moteus 控制器之前，需要配置若干关键参数。这些参数定义了运行限制、控制行为，并配置系统以匹配你的具体应用。

## 必备的配置参数

以下参数应仔细检查，对于几乎每个应用，都可能需要以定制化的方式进行配置。

### 位置限制

**`servopos.position_min` 和 `servopos.position_max`**

它们定义了控制器在位置控制模式下允许的运动范围。尝试从该范围之外启动将会触发故障；运行期间若超出该范围，则不会施加任何转矩以进一步移出这些限制。如果不想要这些限制，应使用 `nan` 来禁用它们。

### 电流限制

**`servo.max_current_A`**

施加到电机的最大相电流。无论发送何种命令，都可以用它来限制系统所能产生的最大转矩。请根据电机的峰值电流额定值以及散热能力来设置此值。

### 速度限制

**`servo.max_velocity`**

限制电机在不再产生转矩之前所允许达到的最大速度。它作为一个安全限制，以防止可能损坏电机或机械系统的过高转速。

**`servo.default_velocity_limit` / `servo.default_accel_limit`**

控制电机为达到位置和速度目标所能加速和旋转的快慢。裸板出厂时这些值未设置，而开发套件则带有观感舒适的值。请调整这些值以匹配你的应用性能需求。

### 减速箱缩放

**`motor_position.rotor_to_output_ratio`**

一个减速箱缩放因子。减速齿轮箱应配置为小于 1 的数值（例如，4 倍减速齿轮箱为 0.25）。这会影响报告的位置、速度和转矩，将它们缩放为表示输出轴的值，而非电机轴的值。

### 设备标识

**`id.id`**

此设备使用的 CAN-FD ID。总线上的每个控制器都必须具有唯一的 ID。有效 ID 范围为 1 到 126。如果你将其设置为 1 以外的值，请注意：除非你的 tview 和控制器固件都晚于 2025 年末，否则你需要用以下方式重启 tview：

```
python -m moteus_gui.tview -t N
```

其中 N 是新的 ID，以便发出 `conf write` 来保存参数。

### PID 参数

**`servo.pid_position`**

位置控制回路的 PID 参数。有必要对这些参数进行整定，这并不困难，但必须在执行校准之后进行。完成校准过程后，你将进入 [PID 整定指南](../guides/pid-tuning.zh-CN.md)。

## 保存参数

所有参数（包括 ID）都临时存储在易失性存储器中，断电后将被丢弃。要将这些参数保存到持久存储，需要输入：

```
conf write
```

到 tview 的诊断控制台中。
