# 校准（Calibration）

如果你是从一块全新的 moteus 裸板开始，则需要针对所连接的电机对其进行校准，之后才能使用任何控制模式。在以下情况下需要进行校准：

- 首次使用一块新的 moteus 裸控制器
- 更换为不同的电机
- 改变了控制器与电机之间的机械对位关系
- 某些会影响电机特性的配置变更之后

开发套件通常已经预校准，除非更换电机，否则无需执行此步骤。

## 校准命令

要校准你的 moteus 控制器，请运行以下命令：

```bash
python3 -m moteus.moteus_tool --target 1 --calibrate
```

如果你已将控制器配置为使用不同的 ID，请将 `1` 替换为相应的 CAN-FD ID。

## 重要安全警告

**警告：校准期间所连接的电机必须能够自由旋转。**

在校准过程中：

- 电机将沿两个方向旋转
- 电机将达到较高的转速
- 请确保不存在任何机械障碍物
- 请勿对电机轴施加任何负载
- 使手部和物体远离电机以及任何已连接的机构

校准过程会测量电机的电气特性以及编码器对齐情况，这需要电机能够不受限制地运动。

## 替代校准参数

### 有限旋转

如果事先知道电机的 Kv，可以减少校准所需的运动量。在这种情况下，请额外指定一个命令行参数：

`--cal-force-kv X`

其中 X 是电机的 Kv。在此模式下，moteus 只会使转子沿每个方向旋转 360 度，并且不会执行高速运动。

### 非常小或非常大的电机

在编码器校准过程中，moteus 会对电机施加恒定的功率。默认功率 7.5W 对许多电机来说是足够的，但并非所有电机都如此。如果电机非常小，施加这么大的功率可能会导致其过热或烧毁。如果电机非常大，7.5W 可能不足以使其转动。可以通过指定以下参数来改变该值：

`--cal-motor-power X`

其中 X 是要施加的功率（单位：瓦）。小型电机需要更小的值，大型电机可能需要更大的值。

### 更新编码器与转矩带宽

如果你的应用需要非常快速地改变转矩或速度，则还有一些额外的注意事项。

**转矩带宽**：你可能希望在校准过程中配置一个替代的“带宽”参数。带宽的具体值可以粗略地用来估算 moteus 改变输出转矩的速度，以及它感知速度和位置变化的速度。例如，默认带宽为 200Hz。这意味着，作为一个粗略的数量级，moteus 可以在 1/200 = 5ms 内改变转矩或观察到速度变化。更高的带宽值会导致控制器和电机发出更多可闻噪声。除了可闻噪声（可能相当显著）之外，提高带宽并没有太多弊端。

`--cal-bw-hz X`

**`servo.max_current_desired_rate`**：moteus 会限制给电机的指令相电流的变化速率。默认情况下，该值设为 10000A/s。对于电流限制为 100A 的 moteus-r4 而言，这意味着从 -100A 到 100A 满量程变化需要 20ms。许多高带宽应用会需要大于此值的速率。

## 故障排查

如果你在校准过程中遇到问题，例如：

- 电机不转动
- 校准失败或报错
- 电机行为异常

请参考[故障排查指南](../troubleshooting/calibration.zh-CN.md)了解常见问题及解决方法。
