# 电气设置（Electrical Setup）

为了在不损坏 moteus 的情况下使用它，必须妥善处理电气连接与配置。本节将说明如何操作。

## 电气连接

**电机**：电机的相线应焊接到标注为 A、B、C 的焊盘上。顺序无关紧要。不同控制器之间焊盘的位置有所不同。如果希望反复插拔，可以使用直插式连接器，例如 MR30、MR60 或子弹头连接器。

**电源**：电源通过板载 XT30 连接器提供；在可板载安装的 moteus 控制器上，则通过与 A、B、C 相焊盘交错排布的电源焊盘提供。电源输入*没有*反极性保护。在施加电源之前应三重复核极性，否则可能导致不可逆的损坏。XT30 连接器上有清晰的 '+' 和 '-' 标记，可用于识别正负输入。

如果你不确定，可以在以下位置找到所有控制器的引脚定义图：[引脚定义图](../reference/pinouts.zh-CN.md)

!!! note "热插拔"
    切勿热插拔 XT30 连接器，这一点很重要。XT30 连接器（以及所有非防打火连接器）都应在施加电源*之前*连接好。如果你看到或听到打火，说明你施加电源的顺序错误了。请参阅下面关于浪涌电流管理的章节。

## 焊接与线缆制作技巧

当使用不当的技术将导线连接到 moteus 控制器，或使用不当的技术制作电源线缆时，moteus 控制器可能会损坏。

### 相线焊接

moteus 与所控制电机之间的连接必须质量过硬。质量差的焊点会导致电阻间歇性变化、打火以及高电压瞬变。高质量的焊点需要：

* 足够的助焊剂，以清除导线和过孔上的氧化物
* 足够的温度，使整根导线和过孔都热到焊料能够润湿所有表面

对于前者，通常除了许多焊料自带的松香芯之外，还需要额外加入大量助焊剂。对于后者，可能需要大功率烙铁、粗烙铁头，以及看似很长的时间。如果焊料接触过孔或导线的任何部位时不能立即熔化并浸润，则温度肯定不够。通常会在烙铁头与导线之间放置少量焊料作为导热介质。然后将烙铁搁在过孔和导线上 5-30 秒，直到看起来初始焊料已完全浸润进过孔。然后可以继续加焊料，直到在过孔周围形成干净、光滑的圆角，并向上浸润到导线。

完成后，可以检查孔背面，如果成功，焊料会部分向下浸润出过孔，到达另一侧，并在那里也形成干净、光滑的圆角。

### 电源连接器化

为使 moteus 在不损坏的情况下运行，用于传输电源的 XT30 连接器必须形成牢固、非间歇性的连接。与焊接不良一样，间歇性连接会导致电感尖峰，从而损坏控制器上的元件。

连接器正常工作时，应需要适度的插入力，且插入后连接器不应有太多“晃动”。

XT30 在配接时不适用于承受任何显著的机械力。对于线缆可能弯折的任何应用，都应使用应力消除措施，使连接器不承受任何力。即使系统仅有一次“失控”，连接器也可能损坏，而较轻微的机械应力可能会导致加速疲劳和失效。

如果观察到打火，那*肯定*是个问题，系统应断电，直到更换连接器并针对导致该事件的原因采取缓解措施。

正品 AMASS 连接器在假设无其他机械损伤的情况下额定可插拔 1000 次，但杂牌连接器的公差可能更差，甚至可能连一次都难以形成可靠连接。


### 长菊花链

当在一个系统中将超过 3 个 moteus 控制器或伺服连接到同一条电源或 CAN 链上时，应考虑额外的因素。

1. 对于超过 3 个单元的链，建议使用 T 形分支供电，而不是使用菊花链电源连接器。连接器轻微的未插到位或微打火会随着长链的控制器而被放大。

2. CAN 总线的电气性能可能成为限制因素。要在默认的 5Mbps 下运行，需要确保 CAN 线是双绞的、所有压接质量都高，并且已安装终端电阻。可能需要分裂终端（split termination），即将两个 60 欧姆电阻串联，并在电阻中心抽头与地之间连接一个小滤波电容。建议使用 4.7nF 电容。如果仍不够，可以禁用 BRS，仅以 1Mbps 运行。使用 `moteus_tool` 或 `tview` 时，可以使用 `--can-disable-brs` 标志。

mjbots 出售可为此目的使用的 CAN 终端电阻：[https://mjbots.com/products/jst-ph3-can-fd-terminator](https://mjbots.com/products/jst-ph3-can-fd-terminator)

## 浪涌电流管理

moteus 控制器具有大容量、低 ESR 的直流滤波电容，这正是它们能实现小尺寸的原因。因此，施加电源时必须小心。如果连接器被“热插拔”，会产生极大的瞬态电流，可能损坏 moteus 或系统中的其他元件。当多个 moteus 控制器连接到同一电源总线时，这些挑战会被放大。

可能的解决方案：

**电源**：如果使用墙上电源适配器，可以依靠它提供“软启动”功能。请确保所有 moteus 控制器都在*开启电源（通过打开开关或插入墙上插座）之前*连接到电源。

**防打火连接器**：存在诸如 XT90-S 之类的防打火连接器，其内置了一个功率电阻，在主电源施加之前先接触。可以使用它们，但有几个缺点：

1. 必须始终遵守正确的连接顺序。除非 XT90-S 是*最后*连接的，否则可能产生浪涌瞬变。
2. 如果不遵守内置电阻的额定功率，它会无声地失效，导致完全没有预充电保护。

**有源预充电电路**：mjbots 出售 [mjpower-ss](https://mjbots.com/products/mjpower-ss) 和 [power_dist](https://mjbots.com/products/mjbots-power-dist-r4-5b)，两者的主要功能都是对容性负载进行逐步预充电。其他有源预充电系统也可能可行。

## 再生制动安全

可以命令 moteus 急剧地减速负载，无论是直接响应命令，还是由于外部扰动。在制动负载时，moteus 默认将产生的功率施加到输入直流总线上。

如果这些功率无处可去，就会导致问题。电压可能无限升高，轻微情况下会导致总线上所有设备的 CAN 收发器失效，严重情况下可能使主板上的主 MOSFET 或其他元件爆炸。

以下是关于 moteus 用于应对这一问题的设施你应该了解的内容，以及你可以做什么来使设计更安全。

### 软件保护

moteus 有若干可配置机制来限制再生电压升高。完整的整定细节，请参阅[过压故障 34 排查](../troubleshooting/overvoltage-fault-34.zh-CN.md)。

**加速度限制**：设置 `servo.default_accel_limit`（或按命令的 `accel_limit`）可控制制动转矩施加的快慢。这是限制再生功率注入速率最直接的方式。

**再生功率限制**：设置 `servo.max_regen_power_W` 可限制制动期间允许回流到总线的功率。多余的能量会通过 d 轴电流注入提前耗散在电机绕组中。对于无法吸收任何再生能量的电源，请将此值设为较小的数值，例如 `10`，甚至 `0`。

**磁通制动**：当总线电压升至 `servo.max_voltage - servo.flux_brake_margin_voltage` 之上时，moteus 会在电机绕组中耗散能量以抵抗电压进一步升高。这由 `servo.flux_brake_margin_voltage` 和 `servo.flux_brake_resistance_ohm` 控制。

### 硬件设计注意事项

以下设计注意事项可用于在发生过压时尽量降低硬件损坏的风险。它们不能替代在越来越严苛的情况下进行验证，但可以帮助你从一个好的起点开始。

- *严格限定过压故障 / 磁通制动的范围*：可以降低总线上所有设备的配置参数 `servo.max_voltage`。这样，当电压超过此值时将触发故障，并与 `servo.flux_brake_margin_voltage` 结合，选择 moteus 尝试耗散能量以防止过压情况发生的点。建议将此值设置为不低于最高预期电源电压 5V 以上。

- *由电池供电，而不是 PSU*：未充电时，电池能够吸收电流，以尽量减小过压瞬变。但是，如果电池已充满电，大多数电池管理系统会大幅降低允许的充电电流。因此，只有当电池从未充电到例如 75% 或 80% 的电量状态以上时，电池才可作为缓解措施。

- *降低整体系统电压*：如果你使用例如 10S 电池运行 moteus 控制器，峰值输入电压可高达 42V。这没有给再生负载留下太多裕量。对于承受急剧再生负载且没有始终连接可充电电池的应用，建议不超过 8S（峰值 33.6V）。

- *使用既能吸收也能输出的电源*：使用廉价的实验室电源供电是最危险的，因为它们通常只能输出电流而不能吸收电流。需要的是“双象限”电源。
