# 机械设置（Mechanical Setup）

要使用集成到 moteus 中的板载同轴编码器，必须小心安装控制器，以确保正确的对齐和持续的配准。

## 机械安装

如果使用默认板载编码器，则必须执行以下步骤：

1. 应将一个径向磁化的感应磁铁连接到转子（*不是*任何减速器或连杆的输出）。固定必须刚性，不允许打滑。通常需要粘合剂，可以使用氰基丙烯酸酯或环氧树脂。
2. moteus 控制器安装时，编码器必须 (a) 在感应磁铁上方横向居中，且 (b) 气隙约为 2mm。该安装必须刚性，不允许打滑。

!!! note "moteus-r4 安装"
    与其他 moteus 控制器不同，moteus-r4 的编码器*不是*位于螺栓孔图案的中心，请查看[2D CAD 以了解详情](https://github.com/mjbots/moteus/blob/main/hw/controller/r4.5/20210124-moteus-controller-r45-mechanical.pdf)。

!!! note "3D 打印安装座"
    如果使用 3D 打印安装座，应注意确保安装座不会翘曲。PLA 和其他低温耗材在室温下受力会翘曲，暴露在电机控制器等热源下时会翘曲得更厉害。建议使用 PETG、PC 或专为在预期工作温度下不翘曲而设计的耗材。

## 其他注意事项

安装时还有一些额外的注意事项，其中一些基本属于常识，另一些则是 moteus 特有的。

### 防止碎屑和杂散导体

建议在运行期间将 moteus 控制器与环境进行机械屏蔽，以防止接触杂散导体、污垢或碎屑。在系统通电时接触上述任何物体都可能导致失效。

同样，应避免在系统通电时对其进行操作或作业。

### moteus-n1 光敏感性

moteus-n1 有一个对光敏感的电压调节器，暴露在阳光下会失效。用于容纳系统的外壳应是不透明的。如果由于某种原因无法使用外壳，可以在电压调节器 IC 上覆盖不透明环氧树脂。

moteus-c1、moteus-r4 和 moteus-x1 无需考虑光敏感性问题。

机械安装完成后，继续进行[电气设置](electrical-setup.zh-CN.md)，以连接电机相线和电源。
