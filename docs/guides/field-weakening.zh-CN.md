# 弱磁（Field Weakening）

## 背景

moteus 控制器用于驱动永磁同步电机（PMSM）。在正常运行时，PMSM 能达到的最大空载转速由下式决定：

```
max_speed_hz = Kv * supply_voltage / 60
```

使用 moteus 时，还要乘入另外两个常数：空间矢量调制常数和最大调制因子常数。截至 2026 年，二者结合大约为：

```
k_svpwm * k_maxmod ~= 0.8
max_speed_hz = k_svpwm * k_maxmod * Kv * supply_voltage / 60
```

之所以存在这一限制，是因为只有当电源电压大于电机运动时产生的反电动势时，控制器才能施加转矩。可以在不产生转矩的轴（D 轴）上施加电流，以降低有效的反电动势常数，从而提高有效的 Kv 常数。这种效应称为“弱磁”。该效应的幅度取决于电机结构。通常，内置式永磁同步电机（IPMSM）能够以适度的功率消耗实现相对较大的弱磁。大多数爱好级和低成本无刷电机是表贴式永磁同步电机（SPMSM），对于这类电机，弱磁有时在合理的功率预算下可行，有时则不可行。

moteus 支持在弱磁状态下运行，从而在给定电源电压下扩展电机可达到的最大转速。这有几点注意事项：

- **功率**：启用弱磁后，运行电机所需的功率将相同或更大。使用弱磁时，在略低于空载转速时就会开始额外消耗功率，以实现最大转矩。在较高转速下，电源消耗的功率以及以热能形式耗散在电机和控制器中的功率可能非常大。其用量还与所配置的最大电流成正比，因此如果你的应用不需要全额电流，降低 `servo.max_current_A` 可能会有帮助。
- **校准**：弱磁依赖于 D 轴电感的特定值。对于许多电机，该值在不同 D 轴电流下会显著变化。为了稳定运行，moteus 需要一个更长的校准步骤来测量这种 D 轴电感饱和缩放效应。
- **稳定性**：对于某些电机，必须在比电源电压足够高（从而不需要弱磁）时所需的带宽更高的 `--cal-bw-hz` 下校准 moteus，才能在弱磁状态下以某种转速运行。以更高的 `--cal-bw-hz` 校准会导致所有转速下的可闻噪声增加。
- **硬件限制**：即使启用了弱磁，moteus 也会将最大转速限制为不超过所用 moteus 控制器以其最大额定输入电压供电时所能达到的转速。因此，如果你已经在接近最大额定板载电压下运行控制器，那么通过弱磁所能获得的转速增益可能很小或为零。

可以使用 [moteus 性能分析工具](https://mjbots.github.io/moteus/mpat.html) 来估算给定系统在启用或禁用弱磁时所需的功率和性能。

## 用法

在 moteus 上使用弱磁需要执行校准步骤并设置配置值。此外，还有一些可以监控的诊断值。

### 校准

校准时应执行 D 轴电感缩放步骤。

```
python -m moteus.moteus_tool -t 1 --calibrate --cal-measure-ld-saturation
```

这需要数分钟的运行时间，并且可能需要主动冷却电机或控制器才能成功。

校准得到的 `L_d` 缩放值对于同一电机设计的所有个体几乎相同，因此可以将该参数从一个控制器复制到另一个控制器，从而在多个实例中只需进行一次校准。

```
servo.inductance_d_scale
```

### 配置

要启用弱磁运行，请使用此配置：

```
servo.fw.enable 1
servo.bemf_feedforward 1
```

使用弱磁时，应将 `servo.bemf_feedforward` 设为 1，以便控制器能够正确预测反电动势电压，并在高转速下保持稳定运行。

### 监控

运行时，可以监控一些诊断值：

`servo_stats.motor_base_velocity`：这是弱磁开始生效的转速。高于此转速时，将向电机施加额外功率（随转速增加），以实现高于空载转速的运行。

`servo_stats.motor_max_velocity`：这是 moteus 允许的最大转速。请注意，这不是连续额定转速，因为在较大弱磁水平下运行时，电路板或电机的温度可能迅速超过配置的限制。

`servo_stats.fw.id_A`：当前用于降低反电动势常数的 D 轴电流量。

## 限制

- **电路板最大电压**：moteus 会限制弱磁转速，使电机产生的反电动势绝不超过 `servo.max_voltage` 减去一个适当的裕量
- **最大 D 轴电流**：`servo.fw.max_current_ratio` 乘以 `servo.max_current_A`，以确定可用于弱磁的最大 D 轴电流
- **热性能**：弱磁通过向电机施加*更多*功率来运行。这意味着温度会上升得更快，从而降低热性能。
