# 编码器配置参考

本页包含高级编码器配置的详细技术参考。

## 概述

moteus 包含一个板载的轴上磁编码器（magnetic encoder），并支持多种使用外部编码器的选项。要理解如何使用它们，我们首先需要知道 moteus 需要编码器完成的两件事：

- *换相（Commutation）*：moteus 需要知道定子与转子之间的电气关系，才能施加转矩。
- *输出（Output）*：moteus 需要知道输出轴的位置和速度，才能跟随命令的轨迹。

默认情况下，板载磁编码器（AS5047P）被假定用于检测转子。它也被用作输出的位置和速度来源，并受可配置减速比（reduction ratio）约束。

配置分 3 个阶段进行：首先是辅助端口（auxiliary port）配置，其次是编码器源配置，最后是输出配置。

## I/O 引脚能力

- **Con**：连接器上的引脚编号
- **Aux**：用于在 `aux?.pins.X` 中配置该引脚的编号
- **SPI**：串行外设接口（Serial peripheral interface）支持
- **ADC/Sin/Cos**：支持模拟输入以及正弦/余弦输入
- **I2C**：集成电路间（Inter-integrated circuit）协议
- **HW Quad/PWM**：支持“硬件”正交输入和 PWM 输出

## 引脚能力

可以使用以下能力。有些在任何引脚上都受支持，另一些仅在特定引脚上受支持。

### 软件正交输入

引脚：任意

软件正交功能使用 GPIO 引脚读取增量正交编码器。它能够无差错地以每秒 200,000 计数进行计数，但会产生随计数率增加的处理器开销。更高的开销意味着响应 CAN 消息的延迟会增加。

### 霍尔传感器

引脚：任意

需要 3 个霍尔传感器输入。对于许多霍尔传感器，必须为相关辅助端口引脚配置上拉。

当使用霍尔效应传感器作为换相源时，使用 moteus_tool 校准需要传递 `--cal-hall` 选项。

### 索引

引脚：任意

这是一个单引脚，当编码器处于已知位置时为高电平。它可以由 ABI 输出的“I”信号或专用的归位传感器提供。

### GPIO 输入

引脚：任意

任何引脚都可以指定为 GPIO 输入。其值可以通过诊断或寄存器协议读取。

### I2C 主机

引脚：特定

可以以高达 200Hz 的速率周期性地轮询 1 到 3 个 I2C 设备。moteus r4.5/8/11 上的关联引脚具有永久配置的 2kohm 上拉电阻。

### SPI 主机

引脚：特定

支持多种基于 SPI 的外设。此模式也用于板载编码器，启用时会占用辅助端口 1 上的 CLK、MOSI 和 MISO 引脚。

### 硬件正交输入

引脚：特定

硬件正交引脚使用微控制器外设以任意速度处理正交输入，且无处理器开销。

### 正弦/余弦

引脚：特定

支持具有可配置共模电压的模拟正弦/余弦输入。

### 模拟输入

引脚：特定

可以通过诊断或寄存器协议读取任意模拟输入。

### UART

引脚：特定

支持多种异步串行编码器和调试设施。

moteus-n1 和 moteus-x1 还额外具有连接到 aux1 引脚 D 和 E 的硬件 RS422 收发器，可以通过配置启用。如果将 RS422 引脚 Y 连接到 A，并将 RS422 引脚 Z 连接到 B，则可以使用像 CUI AMT21x 这样的 RS485 设备。

### BiSS-C

引脚：特定

要配置 BiSS-C 编码器，需要两个引脚。一个用于发送，必须在同时支持 UART TX 能力和硬件正交输入的引脚上。另一个引脚不受限制，用于接收。在 moteus-n1 和 moteus-x1 上，aux1 的 D/E 连接到板载 RS422 收发器，可直接用于连接 BiSS-C 编码器。

## 引脚配置

辅助端口配置分两步完成。

首先，将 `aux[12].pins.X.mode` 值设置为每个引脚的适当能力。`aux[12].pins.X.pull` 可用于为某些模式配置可选的上拉或下拉。

其次，必须在 `aux[12]` 的某个能力特定部分中配置相应能力。例如，对于每个辅助端口，`aux[12].spi` 中的 SPI 配置有一个 `mode` 用于选择从设备是什么，以及一个 `rate_hz` 用于定义 SPI 外设的频率。任何未使用的能力部分都必须被禁用。默认情况下，不同的 moteus 控制器在某些辅助端口上已将 UART 配置为串行控制模式，可能需要将其禁用。

对于 I2C 端口，最多可配置 3 个不同的从设备，分别在 `aux[12].i2c.devices.[012]` 中。

`aux[12]` 中的诊断值可用于监控因配置错误或操作错误而产生的错误。

## 编码器配置

除了配置引脚外，大多数编码器还需要在端口级别进行额外配置。这些可配置选项中的大部分记录在[配置参考](configuration.zh-CN.md)中。

## 源配置

辅助端口配置完成后，接下来应在 `motor_position.sources` 中配置编码器源。最多可配置 3 个源，可用类型大致对应于辅助端口提供的类别。通常，源 0 用于换相所用的传感器。

对于每个源，`motor_position.sources.[012].aux_number` 应为“1”或“2”，以选择应从哪个辅助端口读取传感器。`motor_position.sources.[012].type` 选择传感器类型。对于基于 I2C 的源，`motor_position.sources.[012].i2c_device` 选择该辅助端口上的*哪个* I2C 设备被使用。

对于仅增量的源（如正交），可在 `motor_position.sources.[012].incremental_index` 中配置源级别的索引。如果需要增量源为换相提供位置，则应使用此设置。

每个源可以在 `motor_position.sources.[012].reference` 中标记为测量转子或输出。

每个源都有决定如何将设备提供的原始值映射为旋转角度的配置。`cpr` 是每圈计数数，`offset` 提供整数计数偏移，`sign` 可用于反相读数。最终读数为 `(raw + offset) * sign / cpr`。

最后，每个源都有一个可配置的低通滤波器，截止频率由 `motor_position.sources.[012].pll_filter_hz` 设置。可将其设置为 0 以禁用滤波器。如果禁用，对于本身不提供速度的传感器，将不会插值出速度。

## 输出配置

第三个主要阶段控制电机控制器如何使用这些源。某些源选择可以保留为 -1，这会禁用该功能。

`motor_position.commutation_source` 选择哪个源用于为换相提供转子位置。通常保留为源 0，并且是必需的。注意，不建议使用正交源进行换相，因为它们可能丢失计数，并且每次上电都需要额外的应用层归位支持。

`motor_position.output.source` 选择哪个源用于提供输出位置和速度，并且是必需的。

`motor_position.output.offset` 和 `motor_position.output.sign` 用于变换输出位置，以实现给定的零点位置和旋转方向。

`motor_position.output.reference_source` 可选地配置一个源，该源仅用于在启动时消除输出位置的歧义。例如，它可以是一个低速率的基于 I2C 的传感器，或者由归位开关配置的索引源。

最后，`motor_position.rotor_to_output_ratio` 定义转子每转一圈输出转动的圈数。这用于将相对于一个定义的传感器读数映射到另一个。对于齿轮减速器（几乎所有配置），此值将小于 1。例如，4 倍齿轮减速应输入为 0.25。
