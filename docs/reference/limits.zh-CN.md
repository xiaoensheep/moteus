# 应用限制

## 位置

上报和命令的位置被限制在 +-32768.0 圈以内。

如果满足以下任一条件：

a. 位置被命令为特殊值（NaN 或最大负值），或
b. kp 项为零，无论是通过配置还是“kp scale”

那么控制器可以安全地从最大可能位置“回绕”（wrap around）到最大负位置，反之亦然。这在速度控制应用中很有用。

上报和命令的位置在作为命令接收或上报给客户端时，在内部被视为 32 位浮点值。因此，当位置幅值较大时，位置分辨率会降低。等于板载编码器全部能力（约 0.09 度）的分辨率可保持到 +-2048.0 圈的位置。在最大可能位置，此分辨率降低到约 1.44 度。注意，这仅适用于从客户端接收或上报给客户端的值。在内部，位置的控制和 PID 反馈在积分空间中工作，并在整个可用控制包络内表现一致。

## 速度

可以命令的最小可用机械速度为每秒 0.0001 圈。这相当于每秒 0.036 度。

可以命令的最大机械速度为 28000 rpm，或在任何减速器之前约每秒 467 圈。注意，大多数电机在机械或电气上都无法达到此速度。

最大电气频率为 4kHz。
