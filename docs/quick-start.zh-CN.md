# 快速入门指南

刚接触 moteus？请按顺序完成以下各节。第一组适用于拥有裸板的情况，第二组适用于从开发套件开始的情况。

## 裸板设置概览

如果您拥有裸 moteus 电路板和电机，以下步骤适用于您。

1. **[机械设置](guides/mechanical-setup.zh-CN.md)** - 安装编码器磁铁与控制器
2. **[电气设置](guides/electrical-setup.zh-CN.md)** - 连接相线与电源
3. **[软件安装](guides/software-installation.zh-CN.md)** - 安装并运行 tview
4. **[配置](guides/configuration.zh-CN.md)** - 设置关键参数
5. **[编码器概览](guides/encoder-overview.zh-CN.md)** - 了解编码器选项（如果使用外部编码器）
6. **[校准](guides/calibration.zh-CN.md)** - 针对您的电机校准控制器
7. **[PID 整定](guides/pid-tuning.zh-CN.md)** - 整定位置控制常数
8. **[控制模式](guides/control-modes.zh-CN.md)** - 了解如何控制电机

## 开发套件用户

如果您从开发套件开始，电机已经安装、配置、校准并整定完毕。您的工作会更轻松，太棒了！只需按照以下步骤操作：

1. **[软件安装](guides/software-installation.zh-CN.md)** - 安装 tview
2. **[控制模式](guides/control-modes.zh-CN.md)** - 开始控制您的电机
